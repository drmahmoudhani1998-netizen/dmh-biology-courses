# DMH Biology Scroll Website

Creative one-page scrolling landing page for DMH Biology courses.

## Files
- `index.html`
- `styles.css`
- `script.js`
- `assets/dmh-logo.png`

## Run locally
Open `index.html` directly, or use VS Code Live Server.

## Publish on GitHub Pages
1. Create a new GitHub repository.
2. Upload all files while keeping the same folder structure.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select `main` and `/root`.
6. Save.

## Before publishing
Replace the WhatsApp placeholder in `script.js` with your real link, e.g.
```js
window.location.href = "https://wa.me/20XXXXXXXXXX";
```
